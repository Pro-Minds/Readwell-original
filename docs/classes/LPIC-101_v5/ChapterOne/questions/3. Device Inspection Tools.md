### Multiple Choice Questions

1. **What does the `lspci` command primarily list?**
    - A) USB devices
    - B) PCI devices
    - C) Network connections
    - D) Kernel modules  
      **Answer**: B) PCI devices

2. **Which command would you use to get detailed information about a specific PCI device?**
    - A) `lspci -d [device_address]`
    - B) `lspci -s [device_address] -v`
    - C) `lsusb -v`
    - D) `modinfo [module_name]`  
      **Answer**: B) `lspci -s [device_address] -v`

3. **What type of devices does the `lsusb` command display?** (Select all that apply)
    - A) Keyboards
    - B) Network cards
    - C) External storage
    - D) Graphics adapters  
      **Answers**: A) Keyboards, C) External storage

4. **Which command would you use to view all currently loaded kernel modules?**
    - A) `lsusb`
    - B) `lspci`
    - C) `lsmod`
    - D) `modprobe`  
      **Answer**: C) `lsmod`

5. **What information can you obtain from the command `lsmod`?** (Select all that apply)
    - A) Memory usage of modules
    - B) Dependencies between modules
    - C) List of USB devices
    - D) Detailed information about PCI devices  
      **Answers**: A) Memory usage of modules, B) Dependencies between modules

6. **What does the `modprobe` command do?**
    - A) Lists all USB devices
    - B) Loads or unloads kernel modules
    - C) Displays PCI device details
    - D) Updates kernel firmware  
      **Answer**: B) Loads or unloads kernel modules

7. **To remove a kernel module named `snd_hda_intel`, which command would you use?**
    - A) `modprobe -r snd_hda_intel`
    - B) `modinfo snd_hda_intel`0
    - C) `lsmod -r snd_hda_intel`
    - D) `lspci -r snd_hda_intel`  
      **Answer**: A) `modprobe -r snd_hda_intel`

8. **What additional information can be obtained by using `lsusb -v`?**
    - A) Detailed USB descriptors
    - B) List of loaded modules
    - C) PCI device addresses
    - D) Kernel version  
      **Answer**: A) Detailed USB descriptors

9. **Which of the following commands would you use to inspect a specific USB device by its vendor and device ID?**
    - A) `lsusb -v`
    - B) `lsusb -d [vendor:device]`
    - C) `lspci -d [vendor:device]`
    - D) `modinfo [module_name]`  
      **Answer**: B) `lsusb -d [vendor:device]`

10. **What is the primary purpose of the `modinfo` command?**
    - A) To list USB devices
    - B) To display information about kernel modules
    - C) To load kernel modules
    - D) To unload kernel modules  
      **Answer**: B) To display information about kernel modules

11. **Which of the following is NOT a function of `lspci`?**
    - A) Displaying PCI device addresses
    - B) Showing the manufacturer of devices
    - C) Listing USB devices
    - D) Providing details about graphics adapters  
      **Answer**: C) Listing USB devices

12. **Using `lsmod`, what might you check if you are troubleshooting a hardware compatibility issue?** (Select all that apply)
    - A) Active kernel modules
    - B) Module dependencies
    - C) USB device types
    - D) PCI device addresses  
      **Answers**: A) Active kernel modules, B) Module dependencies

13. **What does the `-r` option in the `modprobe` command signify?**
    - A) Reload a module
    - B) Remove a module
    - C) Display module info
    - D) List all modules  
      **Answer**: B) Remove a module

14. **Which command would you use to check if a specific kernel module is loaded?**
    - A) `lsusb`
    - B) `lspci`
    - C) `lsmod`
    - D) `modprobe`  
      **Answer**: C) `lsmod`

15. **Why is it important to inspect kernel modules using tools like `lsmod` and `modprobe`?** (Select all that apply)
    - A) To ensure hardware compatibility
    - B) To manage system memory
    - C) To troubleshoot device issues
    - D) To optimize module performance  
      **Answers**: A) To ensure hardware compatibility, C) To troubleshoot device issues, D) To optimize module performance
