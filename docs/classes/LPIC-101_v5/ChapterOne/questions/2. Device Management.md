### Multiple Choice Questions

1. **What key is commonly used to access the BIOS/UEFI setup during startup?**
    - A) F1
    - B) F10
    - C) Del
    - D) Esc  
      **Answer**: C) Del

2. **Which of the following can be configured in the BIOS/UEFI?** (Select all that apply)
    - A) Boot order
    - B) Network settings
    - C) CPU clock speed
    - D) Operating system settings  
      **Answers**: A) Boot order, B) Network settings, C) CPU clock speed

3. **What does IRQ stand for in the context of BIOS/UEFI settings?**
    - A) Internal Resource Queue
    - B) Interrupt Request
    - C) Integrated Resource Queue
    - D) Input Resource Queue  
      **Answer**: B) Interrupt Request

4. **Which of the following is a primary purpose of customizing hardware settings in BIOS/UEFI?**
    - A) To increase software compatibility
    - B) To manage device power consumption
    - C) To improve hardware performance
    - D) All of the above  
      **Answer**: D) All of the above

5. **What is the function of DMA in BIOS/UEFI settings?**
    - A) To manage CPU temperature
    - B) To allow devices to communicate with memory without CPU involvement
    - C) To control network traffic
    - D) To set the boot priority  
      **Answer**: B) To allow devices to communicate with memory without CPU involvement

6. **In a UEFI system, what is the name of the partition used for booting?**
    - A) Master Boot Record (MBR)
    - B) Boot Configuration Data (BCD)
    - C) EFI System Partition (ESP)
    - D) Primary Boot Partition  
      **Answer**: C) EFI System Partition (ESP)

7. **Which of the following can be adjusted to optimize CPU performance in BIOS/UEFI?** (Select all that apply)
    - A) CPU clock multiplier
    - B) Power-saving modes
    - C) Hyper-Threading
    - D) RAM speed  
      **Answers**: A) CPU clock multiplier, B) Power-saving modes, C) Hyper-Threading

8. **What might happen if the boot order is incorrectly configured?**
    - A) The system may boot faster
    - B) The system may fail to boot
    - C) The system may load the wrong operating system
    - D) Both B and C  
      **Answer**: D) Both B and C

9. **Which of the following statements about BIOS is true?** (Select all that apply)
    - A) BIOS uses MBR for booting.
    - B) BIOS can support larger hard drives than UEFI.
    - C) BIOS is limited to 16-bit processing.
    - D) BIOS settings can affect system performance.  
      **Answers**: A) BIOS uses MBR for booting, C) BIOS is limited to 16-bit processing, D) BIOS settings can affect system performance.

10. **What is the main advantage of UEFI over BIOS?**
    - A) UEFI supports only 32-bit systems.
    - B) UEFI can boot from larger drives and supports modern filesystems.
    - C) UEFI is easier to access than BIOS.
    - D) UEFI does not require a bootloader.  
      **Answer**: B) UEFI can boot from larger drives and supports modern filesystems.

11. **Which of the following actions can enhance security in BIOS/UEFI?** (Select all that apply)
    - A) Disabling unused ports
    - B) Setting a BIOS password
    - C) Enabling Secure Boot
    - D) Allowing remote access to BIOS settings  
      **Answers**: A) Disabling unused ports, B) Setting a BIOS password, C) Enabling Secure Boot

12. **What does the term "boot priority" refer to?**
    - A) The speed at which the operating system loads
    - B) The order in which devices are checked for bootable media
    - C) The amount of memory allocated for boot processes
    - D) The time taken to initialize hardware  
      **Answer**: B) The order in which devices are checked for bootable media

13. **What type of settings can you typically find in the BIOS/UEFI related to peripheral devices?**
    - A) Power management settings
    - B) Device activation options
    - C) IRQ and DMA configurations
    - D) All of the above  
      **Answer**: D) All of the above

14. **In a multi-device setup, why is it important to configure the boot order correctly?**
    - A) To ensure the fastest boot time
    - B) To prevent hardware conflicts
    - C) To ensure the correct operating system loads
    - D) To optimize power consumption  
      **Answer**: C) To ensure the correct operating system loads

15. **Which of the following are tasks you can perform in BIOS/UEFI?** (Select all that apply)
    - A) Update the operating system
    - B) Change the system time
    - C) Configure RAID settings
    - D) Manage user accounts  
      **Answers**: B) Change the system time, C) Configure RAID settings

### Advanced Multiple Choice Questions

16. **Which of the following BIOS settings would likely need adjustment to enable a new graphics card?**
    - A) Boot Order
    - B) Integrated Peripherals
    - C) Power Management
    - D) System Time  
      **Answer**: B) Integrated Peripherals

17. **When configuring IRQ settings manually, which of the following could result in conflicts?** (Select all that apply)
    - A) Assigning the same IRQ to two devices
    - B) Not configuring DMA channels
    - C) Overriding default settings for legacy devices
    - D) Setting IRQs to auto for all devices  
      **Answers**: A) Assigning the same IRQ to two devices, C) Overriding default settings for legacy devices

18. **What happens if Secure Boot is disabled in UEFI?**
    - A) The system will not boot at all.
    - B) The system may allow unsigned drivers or operating systems to load.
    - C) The UEFI firmware will revert to BIOS mode.
    - D) The boot sequence will automatically change.  
      **Answer**: B) The system may allow unsigned drivers or operating systems to load.

19. **In which scenario would you need to enable CSM (Compatibility Support Module) in UEFI?**
    - A) When installing a modern operating system
    - B) When using legacy hardware or operating systems
    - C) To enhance system security
    - D) To improve boot time  
      **Answer**: B) When using legacy hardware or operating systems

20. **What is the maximum size limit for a hard drive when using the MBR partitioning scheme?**
    - A) 2 TB
    - B) 4 TB
    - C) 8 TB
    - D) 16 TB  
      **Answer**: A) 2 TB

21. **Which setting in UEFI allows the user to specify which devices are allowed to boot?**
    - A) Boot Order
    - B) Secure Boot
    - C) Boot Configuration
    - D) Boot Manager  
      **Answer**: B) Secure Boot

22. **If a system fails to boot after changing the boot order, what is the most likely cause?**
    - A) A hardware failure
    - B) Incorrect boot device selected
    - C) BIOS version is outdated
    - D) Power supply issues  
      **Answer**: B) Incorrect boot device selected

23. **Which of the following could be a consequence of enabling "Fast Boot" in UEFI?** (Select all that apply)
    - A) Reduced boot time
    - B) Inability to access BIOS/UEFI settings easily
    - C) Enhanced hardware compatibility
    - D) Skipping hardware checks during boot  
      **Answers**: A) Reduced boot time, B) Inability to access BIOS/UEFI settings easily, D) Skipping hardware checks during boot

24. **What does the term "POST" stand for, and what is its primary function?**
    - A) Power-On Self-Test; to check hardware integrity during boot
    - B) Pre-Operating System Test; to initialize the operating system
    - C) Peripheral On Self-Test; to check connected devices
    - D) Primary Operating System Test; to load the OS  
      **Answer**: A) Power-On Self-Test; to check hardware integrity during boot

25. **Which UEFI feature allows for a graphical interface instead of the traditional text-based BIOS?**

26. **When configuring a RAID setup in BIOS/UEFI, which of the following is NOT a typical RAID level option?**

27. **What is the role of the EFI System Partition (ESP) in UEFI?**

    - B) To hold the UEFI bootloaders and drivers

      **Answer**: B) To hold the UEFI bootloaders and drivers

28. **Which of the following can be a reason for a system to hang during POST?** (Select all that apply)
    - A) A failing hard drive
    - B) Incorrectly seated RAM

      **Answers**: B) Incorrectly seated RAM, C) A malfunctioning GPU

29. **What is the main purpose of the "Boot Override" option in UEFI?**

32. **How does UEFI handle booting from GPT-partitioned disks differently than BIOS with MBR?**

    - B) To allocate address space for hardware devices
