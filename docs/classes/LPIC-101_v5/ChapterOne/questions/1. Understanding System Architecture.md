Here are 15 multiple-choice questions (MCQs) focused on **Understanding System Architecture**, along with correct answers indicated:

### Multiple-Choice Questions

1. **What is the primary purpose of hardware standards in computing?**
    - A) To increase the cost of devices
    - B) To ensure compatibility between different hardware manufacturers
    - C) To limit device performance
    - D) To enhance software development complexity  
      **Correct Answer: B**

2. **Which of the following best describes firmware?**
    - A) A type of hardware component
    - B) Software that initializes hardware and provides an interface to the OS
    - C) An application for user interaction
    - D) A network protocol  
      **Correct Answer: B**

3. **What does the Power-On Self-Test (POST) do?**
    - A) Initializes the operating system
    - B) Checks hardware components for errors during startup
    - C) Formats storage devices
    - D) Updates firmware  
      **Correct Answer: B**

4. **Which of the following is a limitation of the BIOS?**
    - A) Supports larger storage devices
    - B) Operates in 32-bit mode
    - C) Can only boot from GPT partitions
    - D) Limited to disks up to 2TB  
      **Correct Answer: D**

5. **What are the key features of UEFI compared to BIOS?**
    - A) Supports Secure Boot
    - B) Uses MBR for partitioning
    - C) Allows booting from larger disks
    - D) Operates in 16-bit mode  
      **Correct Answers: A, C**

6. **What is Secure Boot?**
    - A) A process to secure physical hardware
    - B) A feature that allows only signed bootloaders to run
    - C) A method to encrypt disk data
    - D) A way to update firmware automatically  
      **Correct Answer: B**

7. **What is the role of the GUID Partition Table (GPT)?**
    - A) To replace MBR for larger disk support
    - B) To provide a backup of BIOS settings
    - C) To manage network configurations
    - D) To increase boot speed  
      **Correct Answer: A**

8. **How does Linux abstract hardware interactions?**
    - A) By using graphical user interfaces
    - B) Through kernel modules (drivers)
    - C) By requiring specific hardware for each device
    - D) By using proprietary software  
      **Correct Answer: B**

9. **What are pseudo-filesystems in Linux?**
    - A) Filesystems that require formatting
    - B) Virtual filesystems that provide real-time data about hardware
    - C) Filesystems used for external storage only
    - D) Filesystems that can only be accessed by root users  
      **Correct Answer: B**

10. **Which of the following statements about UEFI is true?**
    - A) It cannot support multiple operating systems
    - B) It is a modern replacement for BIOS
    - C) It operates solely in 16-bit mode
    - D) It does not allow for firmware updates  
      **Correct Answer: B**

11. **Why is it beneficial for an OS to have uniform control over diverse hardware?**
    - A) It simplifies the user experience
    - B) It increases hardware costs
    - C) It complicates software development
    - D) It reduces system performance  
      **Correct Answer: A**

12. **Which of the following is NOT a feature of UEFI?**
    - A) Secure Boot
    - B) Support for MBR
    - C) EFI System Partition (ESP)
    - D) Faster boot times  
      **Correct Answer: B**

13. **What is one of the main purposes of firmware in a computer system?**
    - A) To manage user applications
    - B) To act as a bridge between hardware and the OS
    - C) To create network connections
    - D) To provide graphical interfaces  
      **Correct Answer: B**

14. **Which of the following statements about Linux and hardware compatibility is true?**
    - A) Linux requires specific drivers for every hardware type
    - B) Linux abstracts hardware interactions through drivers
    - C) Linux has no ability to manage hardware
    - D) Linux only works with certain hardware brands  
      **Correct Answer: B**

15. **What is the significance of hardware standards in relation to Linux?**
    - A) They limit the types of devices that can be used
    - B) They enable Linux to interact with a wide range of hardware
    - C) They complicate the installation of Linux
    - D) They are irrelevant to operating systems  
      **Correct Answer: B**
